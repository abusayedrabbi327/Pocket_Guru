# 📈 PocketGuru

PocketGuru is a comprehensive personal finance application designed to empower students and young professionals. It effortlessly tracks expenses, manages budgets, sets savings goals, and connects users with expert financial consultants through smart analytics and insights.

## ✨ Features

*   **🔒 Authentication:** Secure Login, Sign Up, and OTP verification flows.
*   **📊 User Dashboard:**
    *   Track recent transactions and activity.
    *   Set custom budgets and add financial goals.
    *   Interactive analytics and charts to visualize spending habits.
*   **🤝 Consultant Network:**
    *   Browse and discover verified financial consultants.
    *   Real-time chat integration for direct consultation.
    *   Manage active subscriptions and bookings.
*   **💼 Consultant Portal:**
    *   Dedicated dashboard for financial consultants.
    *   Manage client lists, schedules, and active messages.
    *   Profile setup and customization.

## 🛠️ Tech Stack

*   **Framework:** React 18 & Vite
*   **Language:** TypeScript
*   **Routing:** React Router v7
*   **Styling:** Tailwind CSS v4
*   **UI Components:** Radix UI primitives for accessible components
*   **Animations:** Framer Motion & `tw-animate-css`
*   **Icons:** Lucide React & Material UI Icons
*   **Charts:** Recharts
*   **Forms:** React Hook Form

## 🚀 Getting Started

Follow these steps to get the project up and running on your local machine:

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/abusayedrabbi327/Pocket_Guru.git
   cd Pocket_Guru
   ```

2. Install the dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173` to view the app!

## 📦 Build for Production

To build the application for production, run:
```bash
npm run build
```
This will generate optimized static assets in the `dist/` directory.
